====================== 여기부터 복사 ======================

너는 지금 `pokemon_Ai` 저장소가 있는 내 컴퓨터에서 돌고 있다.
지금까지는 클라우드(웹) 쪽 클로드가 작업했고, **이제 네가 이어받는다.**

## 0. 제일 먼저 할 일 — 순서대로

1. `git fetch origin && git log --oneline -5 origin/claude/ai-design-docs-review-rm4d24`
   최신 커밋이 보이는지 확인한다. 이 브랜치가 작업 브랜치다.
2. `git checkout claude/ai-design-docs-review-rm4d24 && git pull`
3. **`CLAUDE.md` 를 읽는다.** 여기가 일하는 규칙이다. 특히 §1(항상 의심한다).

5. `python3 tests.py` 를 돌린다. **전부 통과해야 한다.** (지금 553개)
6. `python3 samples.py` 로 파티 수를 센다. → **아래 1번이 바로 이것이다.**

## 1. ★ 네가 제일 먼저 해야 할 일 — 수집 결과 올리기

이 컴퓨터에서 champs.pokedb.tokyo 색인 1,718편을 전부 수집해서
`data/samples.json` 이 **파티 2,155개 · 한카리아스 520마리** 가 됐다.

**그런데 그게 깃허브에 안 올라가 있다.** 원격 브랜치에는 아직
**파티 711개**(유효 703개) 짜리 옛 파일뿐이다. 그래서 클라우드 쪽과
집 쪽이 **서로 다른 자료를 보면서** 이야기해 왔다.

→ `docs/수집결과-올리기-프롬프트.md` 에 **그 일만 하는 자세한 지침**이
   따로 있다. 그걸 그대로 따라라. 특히 하면 안 되는 것 6가지를 꼭 읽어라
   (손으로 고치지 마라 / `--ours` `--theirs` 쓰지 마라 / force push 금지 /
    rebase 금지 / 다른 브랜치에 올리지 마라 / 숫자를 추측하지 마라).

이게 끝나야 자료가 하나로 합쳐지고, 그 뒤 숫자들이 다 달라진다
(§5-13 의 `split_score` 는 두 자료에서 모두 확인했지만 나머지는 아니다).

## 2. 이 프로젝트가 뭐냐

포켓몬 **챔피언스**(본편 아님)에서 **"지금 이 상황에서 무엇이 최선의 수인가"**
를 알려주는 도구다. 그래픽은 없고 전투 규칙과 계산만 한다.

사용자는 **전공자가 아니다.** 용어 늘어놓지 말고 평범한 한국어 존댓말로 쓴다.

### 어디까지 됐나

1~7단계 + 실전 도구까지 다 됐다. **지금은 실전에 쓸 수 있는 상태다.**

| | |
|---|---|
| `calc.py` | 데미지 계산기 (한 방) |
| `best.py` | 기술 비교 · 스피드 |
| `battle.py` | 턴 루프 · 교체 · 압정 · 날씨 · 도구 |
| `scout.py` | 상대를 확률 분포로 |
| `forms.py` `combos.py` `samples.py` | 형태 추론 · 기술 조합 · 구축기사 표본 |
| `pick.py` | 6단계 선출 (6마리 중 3마리 + 선봉) |
| `search.py` | 7단계 — 이번 턴의 수 |
| `live.py` | 실전 도구 (글자판) + **창과 같이 쓰는 규칙** |
| `gui.py` | 실전 도구 (창) |
| `faketk/` | 가짜 tkinter — 창을 리눅스에서 돌려 보는 장치 |

### 실행 파일

`.github/workflows/build.yml` 이 윈도우 exe 를 만든다.
**`main` 에 푸시할 때만** 자동으로 돈다. 작업 브랜치에서 돌리려면
Actions 탭 → 「실행 파일 만들기」 → Run workflow 에서 브랜치를 골라 누른다.

## 3. 네가 반드시 지켜야 할 것 (CLAUDE.md 요약 — 원문을 꼭 읽어라)

1. **항상 의심한다.** 사용자가 직접 정한 규칙이다:
   *"토큰을 좀 더 잡아먹더라도 항상 의심해. 이건 필수과정이야."*
2. **숫자를 내놓기 전에, 그 숫자를 만든 입력이 실제로 쓰였는지 먼저 센다.**
3. **놀라운 결과가 나오면 설명을 붙이기 전에 의심한다.**
4. **사용자가 되물으면 그건 거의 항상 맞는 지적이다.**
   이 저장소에서 사용자가 되물은 건은 지금까지 **전부** 실제 결함이었다.
   하나도 빠짐없이 전부다.
5. **의심은 말이 아니라 코드로 남긴다.** 경고를 띄우거나 테스트를 만든다.
6. **검사가 깨졌을 때 검사를 느슨하게 만들지 않는다.**
   전제가 틀렸으면 전제를 고친다.
7. 커밋 메시지는 한국어로, **무엇을 왜 바꿨는지와 숫자**를 적는다.
   틀렸다가 고친 것이면 틀린 과정도 적는다.

### 이 저장소가 고장나는 방식은 하나다 — **조용히 틀어지는 것**

터지지 않는다. 그냥 조금씩(때로는 통째로) 틀린 답을 낸다.
새 기능을 넣을 때마다 먼저 물어라: **"이게 조용히 틀어질 수 있는 자리인가."**

실제로 그렇게 잡힌 것들 (전부 사용자가 되물어서 나왔다) —

| 무엇 | 크기 |
|---|---|
| 아머까오 도구 셋이 미구현이라 맨몸으로 싸움 | 26.6% → 43.2% |
| 물붓기가 장식이었다 (`types_override` 가 계산에 안 감) | — |
| 상대를 한 마리로만 볼 수 있었다 | 한 수에서 **64%p**, 순위 뒤집힘 |
| 나와 있는 놈이 1번이 아니면 계획이 통째로 버려짐 | 세 계획이 **결과까지 동일** |
| 풍선이 땅 기술을 못 막음 (반만 붙은 도구) | **100% → 0%** |
| 메가가 한 파티에 셋까지 나옴 | **34.2% → 0.0%** |
| 칸을 눌러도 후보가 안 떠서 특성을 못 고름 | 기능 자체가 사용 불가였음 |

## 4. 지금 열려 있는 일

1. **수집 결과 올리기** (위 §1). 제일 먼저.
2. **실전 투입.** 사용자가 게임하면서 따라 두고, 진 판(`내기록/대전기록/`)을
   가져와 왜 졌는지 되짚는다. **이게 최종 목표다.**
3. 동반 출현(`samples.partners`)을 `pick.py` 에 연결.
4. 8단계 — 자가발전.
5. 아직 안 붙은 도구 효과 (`battle.APPLIED_ITEM_KINDS` 밖) —
   선제공격손톱·큰뿌리·조임밴드·메트로놈·과사열매·아름다운허물.

### 아직 확인 못 한 가정값

`calc.py` `CONFIG` 에서 `# 미확인` 이 붙은 것들. 전부 본편 값을 가져다 쓴 것이다.
스크린 감소율(1/2) · 날씨 타입 배율(1.5/0.5) · 필드 타입 배율(1.3) ·
압정 수치 · 상태이상 수치 전반.
**실전에서 계산이 어긋나면 여기부터 의심한다.**

사용자가 확인해 줘서 닫힌 것: 자속 1.5 · 급소 1.5 · 화상 물리 반감 0.5 ·
마비 스피드 0.5.

## 5. 너는 집 컴퓨터라서 할 수 있는 것

클라우드 쪽은 이것들이 **안 됐다.** 너는 된다.

| | 클라우드 | 너 |
|---|---|---|
| `champs.pokedb.tokyo` | 403 | **된다** |
| `yakkun.com` | 403 | **된다** |
| `tkinter` (창) | **없다** | 있을 것이다 |
| 화면 | 없다 | 있다 |

→ **창(`gui.py`)을 진짜로 띄워 볼 수 있다.** 클라우드 쪽은 `faketk/` 라는
   가짜 tkinter 로만 돌려 봤다. 생김새·글꼴·배치·단추가 실제로 눌리는지는
   아무도 못 봤다. **네가 처음 보는 사람이다.**
   `python gui.py` 로 띄워서 사용자와 같이 봐라.

## 6. 하지 말아야 할 것

- `main` 에 마음대로 푸시하지 마라. 작업은
  `claude/ai-design-docs-review-rm4d24` 에서 한다.
- `data/samples.json` 을 손으로 고치지 마라 (1MB 넘는 JSON 한 덩어리다).
- 백그라운드 실행에 `&` 를 붙이지 마라 (두 번 작업이 죽었다).
- 수집기가 도는 중에 그 코드를 고치지 마라 (옛 코드로 계속 돈다).
- 포켓몬 이름을 코드에 직접 쓸 때는 `dex.find_pokemon()` 으로 먼저 확인해라.
  **`페리퍼`가 아니라 `패리퍼`다.** 한 글자 틀리면 오류가 안 나고
  그 포켓몬이 조용히 없는 것이 된다.
